SECTION 02

VPN, VLAN, ACL & Proxy

VPN membuat terowongan terenkripsi (memanfaatkan kriptografi Module 05) untuk akses remote yang aman. VLAN (Virtual LAN) memisahkan jaringan fisik menjadi segmen logis terpisah tanpa memerlukan perangkat keras tambahan. ACL (Access Control List) mendefinisikan aturan izin/tolak pada perangkat jaringan (router/switch). Proxy menjadi perantara antara client dan server, dapat digunakan untuk filtering, caching, atau anonimitas.

SECTION 06

Real-World Case Studies

CASE 01 · RECORD-BREAKING DDoSGitHub Memcached DDoS (Februari 2018)

GitHub mengalami serangan DDoS mencapai 1,35 Tbps — pada saat itu yang terbesar tercatat — memanfaatkan teknik amplifikasi melalui server Memcached yang salah dikonfigurasi (terekspos ke internet tanpa autentikasi) di seluruh dunia. Penyerang mengirim request kecil dengan IP source dipalsukan (spoofed) menjadi IP GitHub, sehingga respons Memcached yang jauh lebih besar diarahkan ke GitHub.

TEKNIK

UDP amplification attack via misconfigured Memcached servers

MITIGASI

GitHub menggunakan layanan DDoS protection pihak ketiga, traffic pulih dalam ~10 menit

ROOT CAUSE GLOBAL

Ribuan server Memcached terekspos ke internet tanpa perlu — bukan kesalahan GitHub sendiri

Lesson Learned: DDoS mitigation modern memerlukan kapasitas dan layanan khusus (scrubbing/CDN); perlindungan sisi server saja tidak cukup untuk serangan berskala Tbps.
CASE 02 · DNS HIJACKING CAMPAIGNSea Turtle DNS Hijacking (2019)

Cisco Talos mendokumentasikan kampanye "Sea Turtle" di mana penyerang mengkompromikan registrar dan penyedia DNS untuk mengubah catatan DNS milik puluhan organisasi pemerintah dan swasta di Timur Tengah dan Afrika Utara, mengarahkan traffic email dan VPN ke server yang dikendalikan penyerang untuk mencuri kredensial — tanpa korban menyadari domain mereka sendiri "berbohong".

TEKNIK

DNS record manipulation di level registrar, bukan exploit pada jaringan korban langsung

DAMPAK

Pencurian kredensial melalui MITM pada layanan yang dianggap tepercaya (email, VPN)

Lesson Learned: Keamanan DNS mencakup lebih dari sekadar jaringan lokal — kompromi pada registrar/provider DNS dapat mengelabui pengguna meski jaringan internal mereka aman.

🔍 Think Like a Security Analyst

Skenario: Attack Surface Map UND (Module 03) menunjukkan seluruh jaringan kampus — Wi-Fi mahasiswa, jaringan dosen, dan server SIAKAD — berada pada satu VLAN yang sama "agar semua orang bisa saling akses printer". Tidak ada IDS/IPS terpasang; hanya firewall perimeter dasar.

💡 Pertanyaan Analisis — Network Security UND

1. Risiko konkret apa yang muncul dari satu VLAN untuk semua segmen?
Mahasiswa yang perangkatnya terinfeksi malware (mis. dari Wi-Fi publik) dapat langsung melakukan ARP spoofing atau scanning terhadap server SIAKAD karena berada di broadcast domain yang sama — lateral movement menjadi sangat mudah tanpa perlu melewati kontrol tambahan.
2. Mengapa "hanya firewall perimeter" tidak cukup untuk UND?
Firewall perimeter hanya melindungi dari ancaman EKSTERNAL. Tanpa IDS/IPS dan segmentasi internal, ancaman yang berhasil masuk (mis. via phishing, Module 01) dapat bergerak bebas di dalam jaringan tanpa terdeteksi — inilah mengapa Defense in Depth memerlukan banyak lapisan, bukan satu titik pertahanan.
3. Bagaimana VLAN seharusnya disegmentasi untuk UND?
Minimal 3 VLAN terpisah: VLAN Mahasiswa/Wi-Fi publik (paling tidak dipercaya), VLAN Staf/Dosen, dan VLAN Server (SIAKAD, database — paling sensitif, akses paling terbatas). ACL mengatur komunikasi antar-VLAN hanya untuk kebutuhan spesifik, bukan bebas seperti sekarang.

🏁 Key Takeaways

MODULE 06 — CORE INSIGHTS

  • Firewall menyaring, IDS mendeteksi & alert, IPS mendeteksi & blokir, WAF khusus melindungi layer aplikasi web.
  • VPN, VLAN, ACL, dan proxy adalah kontrol jaringan dasar yang saling melengkapi.
  • ARP spoofing dan DNS hijacking dapat memungkinkan MITM meski jaringan "tampak" aman secara perimeter.
  • DDoS jauh lebih sulit dimitigasi dibanding DoS karena berasal dari banyak sumber terdistribusi.
  • Network segmentation membatasi lateral movement — satu VLAN untuk semua adalah anti-pattern keamanan.
  • Wireshark adalah alat fundamental untuk menganalisis dan memverifikasi traffic jaringan secara langsung.

📖 Glossary

IDS/IPS

Intrusion Detection/Prevention System — mendeteksi (IDS) atau mendeteksi+memblokir (IPS) aktivitas jaringan mencurigakan.

VLAN

Virtual LAN — segmentasi jaringan logis tanpa memerlukan perangkat keras terpisah.

ARP Spoofing

Teknik memalsukan respons ARP untuk mengarahkan traffic korban melalui perangkat penyerang.

MITM

Man-in-the-Middle — penyerang menyisip di antara komunikasi dua pihak untuk menyadap/mengubah data.

DDoS

Distributed Denial of Service — serangan ketersediaan dari banyak sumber terdistribusi (botnet).

Amplification Attack

Teknik DDoS yang memanfaatkan server pihak ketiga untuk memperbesar volume traffic serangan.
