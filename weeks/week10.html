SECTION 03

Antivirus Tradisional vs EDR

🛡 ANTIVIRUS TRADISIONAL

Deteksi berbasis signature file yang dikenal

  • Cepat untuk ancaman dikenal
  • Lemah terhadap fileless/zero-day

🔬 EDR (Endpoint Detection & Response)

Deteksi berbasis perilaku (behavioral)

  • Memantau proses, registry, network endpoint
  • Dapat mendeteksi fileless malware
  • Menyediakan kemampuan respons (isolasi endpoint)

🎯 IOC-BASED DETECTION

Mencocokkan hash/IP/domain dikenal

  • Cepat untuk ancaman terdokumentasi
  • Perlu diperbarui terus-menerus
SECTION 04

Real-World Case Studies

CASE 01 · WORM + SUPPLY CHAIN + WIPERNotPetya (2017)

NotPetya menyamar sebagai ransomware namun sebenarnya adalah wiper (data tidak dapat dipulihkan meski tebusan dibayar). Menyebar awalnya melalui update software akuntansi Ukraina (M.E.Doc) yang disusupi, kemudian menyebar sendiri (worm) memanfaatkan exploit EternalBlue yang sama dengan WannaCry. Perusahaan pelayaran Maersk mengalami kerugian ~$300 juta setelah seluruh sistem globalnya lumpuh dalam hitungan jam.

VEKTOR AWAL

Supply-chain compromise via update software akuntansi (bukan phishing)

PENYEBARAN

Worm — menyebar otomatis antar sistem via exploit SMB, tanpa kontrol C2 terpusat

SIFAT SEBENARNYA

Wiper — data tidak dapat dipulihkan, ransomware hanya kedok

Lesson Learned: Supply-chain compromise (Module 03) dapat menjadi vektor delivery malware yang jauh lebih efektif dibanding phishing individual, dan tidak semua "ransomware" benar-benar dapat dipulihkan meski tebusan dibayar.
CASE 02 · MALWARE-AS-A-SERVICE TAKEDOWNEmotet Botnet (Takedown 2021)

Emotet berevolusi dari trojan perbankan menjadi platform "malware-as-a-service" yang menyewakan akses endpoint yang telah terinfeksi kepada operator ransomware lain. Pada Januari 2021, operasi penegakan hukum internasional (Europol, FBI, dan mitra global) berhasil mengambil alih infrastruktur C2 Emotet dari dalam, mematikan botnet yang telah menginfeksi jutaan endpoint di seluruh dunia.

MODEL BISNIS

Malware-as-a-Service — infrastruktur disewakan ke aktor ransomware lain

PERSISTENCE

Modul tambahan (plugin) memungkinkan Emotet beradaptasi menghindari deteksi

Lesson Learned: Ekosistem malware modern terorganisir seperti bisnis (lih. LockBit, Module 01) — takedown infrastruktur C2 menjadi salah satu strategi mitigasi paling efektif di level global.

🔍 Think Like a Security Analyst

Skenario: Laptop seorang staf admin UND tiba-tiba menjalankan proses PowerShell yang tidak biasa, terhubung ke domain asing setiap 5 menit secara berkala, namun antivirus tradisional tidak mendeteksi apa pun karena tidak ada file mencurigakan di disk.

💡 Pertanyaan Analisis — Endpoint Security UND

1. Mengapa antivirus tradisional gagal mendeteksi ancaman ini?
Pola ini konsisten dengan fileless malware — beroperasi di memori memanfaatkan PowerShell (tools sah bawaan Windows), tidak meninggalkan file untuk dipindai signature-based antivirus. Diperlukan EDR yang memantau perilaku proses, bukan hanya file.
2. Koneksi berkala ke domain asing setiap 5 menit mengindikasikan tahap apa dalam malware lifecycle?
Command & Control (C2) beacon — pola komunikasi periodik yang khas untuk malware menunggu perintah dari attacker atau mengirim data secara berkala.
3. Tindakan containment apa yang harus segera dilakukan, dan bagaimana ini terhubung ke Incident Response (Module 12)?
Isolasi endpoint dari jaringan (memutus koneksi C2) tanpa mematikan proses/sistem sepenuhnya agar bukti (memory dump, proses berjalan) dapat dianalisis forensik (Module 14) — ini adalah tahap Containment dalam NIST IR Lifecycle yang akan dibahas mendalam Module 12.

🏁 Key Takeaways

MODULE 10 — CORE INSIGHTS

  • Setiap jenis malware (virus, worm, trojan, ransomware, spyware, rootkit) memiliki cara penyebaran dan tujuan berbeda.
  • Fileless malware beroperasi di memori memanfaatkan tools sah, membuat deteksi signature-based tidak efektif.
  • Malware lifecycle bergerak dari delivery, execution, persistence, privilege escalation, hingga command & control.
  • EDR memantau perilaku (behavioral), melengkapi antivirus tradisional yang berbasis signature.
  • Supply-chain compromise (lih. NotPetya) dapat menjadi vektor delivery yang jauh lebih efektif dibanding phishing individual.
  • Ekosistem malware modern (malware-as-a-service, lih. Emotet) terorganisir seperti bisnis dengan infrastruktur yang dapat disewakan.

📖 Glossary

Fileless Malware

Malware yang beroperasi di memori tanpa meninggalkan file di disk, sering memanfaatkan tools sah seperti PowerShell.

Persistence

Teknik malware agar tetap aktif meski sistem di-restart.

Command & Control (C2)

Infrastruktur/saluran komunikasi antara malware dan penyerang.

EDR

Endpoint Detection and Response — solusi keamanan endpoint berbasis deteksi perilaku dan kemampuan respons.

Wiper

Malware yang menghancurkan/merusak data secara permanen, sering menyamar sebagai ransomware.

Malware-as-a-Service

Model bisnis di mana infrastruktur/akses malware disewakan kepada aktor lain.
