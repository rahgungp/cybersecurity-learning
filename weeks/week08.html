MODULE 08 · MINGGU KE-08 · EVALUASI TENGAH SEMESTER

UTS — Midterm Cybersecurity Assessment

Cakupan: Module 01–07Bobot: 25% Nilai Akhir Format: Individual, Take-HomeOutput: Cybersecurity Assessment Report
MODULE CONTEXT
MENGUJI Module 01–07 secara terintegrasi
→
NEXT → Minggu 09 — Web & Application Security

UTS BUKAN materi teori baru — ini adalah evaluasi terintegrasi yang menguji kemampuan mahasiswa mengaplikasikan Module 01–07 pada satu organisasi. Mahasiswa akan mengulangi alur analisis yang telah dilatih setiap minggu (Asset → Threat → Vulnerability → Risk → Architecture), kali ini pada skenario yang belum pernah dilihat sebelumnya, tanpa bimbingan langkah demi langkah.

🎯 Learning Objectives yang Diuji

3Vulnerability Analysis & Attack Vector IdentificationModule 02–03
4Risk Assessment (Likelihood × Impact, Risk Matrix)Module 02
5Security Architecture Analysis (Access Control, Network, Zero Trust)Module 04, 06, 07

⚠️ Ketentuan Pengerjaan: UTS bersifat take-home, dikerjakan individual. Mahasiswa BOLEH merujuk kembali materi dan hasil practical Module 01–07 milik sendiri, namun jawaban harus mencerminkan analisis pribadi terhadap skenario UTS (bukan skenario UND yang sudah pernah dibahas). Dilarang keras bekerja sama atau menyalin jawaban antar-mahasiswa.
GRADING RUBRIC

Rubrik Penilaian

KomponenBobotKriteria Penilaian
Asset Identification15%Kelengkapan, kategorisasi tepat, skor CIA impact dijustifikasi
Threat Modeling20%Threat source relevan (taksonomi NIST SP 800-30), attack surface teridentifikasi tepat
Vulnerability Analysis20%Vulnerability, exploit, dan attack vector dibedakan dengan benar dan relevan konteks
Risk Assessment25%Likelihood & impact dijustifikasi, risk matrix diterapkan benar, risk treatment tepat sasaran
Security Architecture Analysis20%Rekomendasi kontrol (access control/network/Zero Trust) relevan dan realistis

Nilai tambahan (bonus) diberikan untuk analisis yang menunjukkan security reasoning — bukan sekadar mengisi template, melainkan menjelaskan mengapa sebuah keputusan diambil, sesuai prinsip "Think Like a Security Analyst" yang telah dilatih sejak Module 01.

DELIVERABLES

Yang Harus Dikumpulkan

UTS DELIVERABLES CHECKLIST

  • Cybersecurity Assessment Report (format PDF/dokumen terstruktur)
  • Asset Inventory dengan skor CIA impact
  • Threat Model (threat source + attack surface + threat actor)
  • Vulnerability & Attack Vector Analysis
  • Risk Register lengkap dengan Risk Matrix
  • Rekomendasi Security Architecture (min. 3 kontrol konkret)
