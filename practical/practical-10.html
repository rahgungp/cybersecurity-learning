PRACTICAL LAB · MINGGU 10 · MODULE 10

Malware / IOC Analysis

⏱ 50–60 menitIndividual Output: Malware/IOC Analysis ReportTools: VirusTotal
📌 Hubungan dengan Materi: Praktik ini menerapkan analisis IOC dan pemetaan MITRE ATT&CK dari Module 10 menggunakan metadata publik yang aman.

🎯 Objective

Mahasiswa mampu menganalisis Indicator of Compromise menggunakan VirusTotal dan memetakan temuan ke MITRE ATT&CK, tanpa menangani sampel malware aktif.

⚠️ Safe Lab Rule: HANYA menggunakan metadata publik yang aman (hash, nama file, domain — disediakan pada skenario). DILARANG mengunduh, menjalankan, atau mendistribusikan sampel malware aktif dalam bentuk apa pun.

💻 Skenario: Endpoint Compromise di UND

Laptop staf admin UND (dari Think Like Analyst Module 10) telah diisolasi tim IT. Analisis awal menemukan proses PowerShell mencurigakan yang menjalankan script tersembunyi, dan koneksi periodik ke domain update-security-check[.]net. Sebuah file bernama svchost_update.exe (BUKAN file sistem asli) ditemukan pada folder Temp dengan hash contoh (fiktif untuk latihan): 44d88612fea8a8f36de82e1278abb02f (ini adalah hash EICAR test file yang aman digunakan untuk latihan, dikenal luas di industri keamanan).

PERIKSA HASH DI VIRUSTOTAL

Kunjungi virustotal.com, cari hash pada skenario. Catat jumlah vendor yang mendeteksi, nama deteksi yang diberikan, dan kapan pertama kali terlihat (first seen).

PERIKSA DOMAIN C2

Catat karakteristik domain update-security-check[.]net — mengapa nama domain seperti ini sering digunakan malware (menyamar sebagai domain resmi)?

PETAKAN KE MITRE ATT&CK

Berdasarkan perilaku pada skenario (file menyamar nama sistem, PowerShell mencurigakan, C2 periodik), identifikasi minimal 3 teknik MITRE ATT&CK yang relevan (kategori: Defense Evasion, Execution, Command and Control).

TENTUKAN TINGKAT KEYAKINAN

Berdasarkan seluruh bukti, tentukan tingkat keyakinan (Low/Medium/High) bahwa ini adalah insiden malware nyata, dengan justifikasi.

REKOMENDASI CONTAINMENT & RESPONSE

Susun rekomendasi langkah containment dan response untuk endpoint ini dan endpoint lain yang mungkin terdampak.

📋 EXPECTED OUTPUT — Malware/IOC Analysis Report

  • Hasil pemeriksaan hash di VirusTotal (jumlah deteksi, nama, first seen)
  • Analisis karakteristik domain C2
  • Pemetaan minimal 3 teknik MITRE ATT&CK dengan justifikasi
  • Tingkat keyakinan insiden + justifikasi
  • Rekomendasi containment & response

Pertanyaan Analisis

  1. Mengapa nama file svchost_update.exe berpotensi menipu pengguna awam maupun beberapa tools keamanan dasar?
  2. Jika ternyata endpoint lain di UND juga menunjukkan pola koneksi serupa ke domain yang sama, apa artinya dari perspektif skala insiden?
  3. Bagaimana IOC (hash, domain) pada latihan ini dapat dibagikan ke organisasi lain untuk membantu deteksi dini (hubungkan dengan konsep Threat Intelligence yang akan dibahas Module 14)?

Checklist Sebelum Submit
