PRACTICAL LAB · MINGGU 09 · MODULE 09

Web Security Testing

⏱ 60 menitIndividual / Kelompok 2 Output: Web Application Security AssessmentTools: OWASP ZAP
📌 Hubungan dengan Materi: Praktik ini menerapkan OWASP Top 10 dari Module 09 pada aplikasi latihan yang sengaja dibuat rentan, dijalankan secara lokal.

🎯 Objective

Mahasiswa mampu menginspeksi HTTP request/response, menemukan potensi kerentanan secara defensif, dan memetakannya ke kategori OWASP Top 10.

⚠️ Safe Lab Rule: WAJIB menggunakan aplikasi latihan yang dijalankan secara LOKAL (mis. OWASP Juice Shop via Docker: docker run -p 3000:3000 bkimminich/juice-shop, atau DVWA). Dilarang keras menargetkan website publik atau sistem pihak lain.

SETUP APLIKASI LATIHAN

Jalankan OWASP Juice Shop atau DVWA secara lokal menggunakan Docker, lalu akses melalui browser di localhost.

$ docker run -d -p 3000:3000 bkimminich/juice-shop $ # buka http://localhost:3000

INSPEKSI REQUEST/RESPONSE

Gunakan Browser Developer Tools atau OWASP ZAP untuk mengamati request saat login, registrasi, dan pencarian produk. Catat parameter yang dikirim.

UJI INPUT VALIDATION (DEFENSIF)

Pada kolom pencarian/form, coba masukkan karakter khusus (mis. ' atau <script>) HANYA untuk mengamati bagaimana aplikasi merespons — tujuannya observasi perilaku, bukan eksploitasi lebih jauh.

UJI BROKEN ACCESS CONTROL

Jika aplikasi memiliki ID pada URL (mis. profil pengguna), amati apakah mengganti ID menampilkan data milik akun lain tanpa verifikasi.

PETAKAN KE OWASP TOP 10

Untuk setiap temuan, tentukan kategori OWASP Top 10 yang paling sesuai dan rekomendasikan mitigasi (bukan cara eksploitasi lebih lanjut).

📋 EXPECTED OUTPUT — Web Application Security Assessment

  • Screenshot/catatan request-response yang diamati (min. 3 skenario)
  • Hasil pengujian input validation dengan pengamatan perilaku aplikasi
  • Hasil pengujian broken access control (jika ditemukan)
  • Tabel temuan: Parameter/Fitur, Kategori OWASP, Rekomendasi Mitigasi

Pertanyaan Analisis

  1. Temuan mana yang paling mengejutkan, dan mengapa aplikasi latihan ini sengaja dibuat rentan pada titik tersebut?
  2. Jika kamu adalah developer aplikasi ini, perbaikan mana yang akan kamu prioritaskan lebih dulu?
  3. Bagaimana WAF (Module 06) dapat membantu MEMBATASI dampak kerentanan yang kamu temukan, meski bukan solusi permanen?

Checklist Sebelum Submit
